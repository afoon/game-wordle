# Scaffodle

This is wordle game clone. Built in React ⚛️.

### [Play Scaffoldle  🪜](https://afoon-scaffoldle-game.netlify.app/)

![Screenshot of the game](src/assets/readme/app-image.png)

## Game modes

### Scaffoldle

This is a twist on the classic wordle game. With every correctly guess word, the next game will have one less row of guesses. When the word is not guessed, a row is added. The game is over when final word is guessed in one try.

![Gif showing game play](/src/assets/readme/game-gif.gif)

### Classic

This is a clone of the classic wordle game.
